# Art Portfolio

## 1. Sobre o projeto

O Art Portfolio é uma aplicação Full Stack desenvolvida para apresentar, organizar e gerenciar trabalhos artísticos pessoais.

O projeto utiliza como referência a organização visual e a experiência de navegação de plataformas como o ArtStation.

Além de seu objetivo funcional, o desenvolvimento tem finalidade educacional, permitindo praticar arquitetura de software, desenvolvimento web, integração de sistemas, bancos de dados e processamento de imagens.

## 2. Tecnologias utilizadas

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### Backend
- Node.js
- Express.js

### Banco de dados
- MySQL

### Processamento de imagens
- Python
- FastAPI
- Pillow

### Controle de versão
- Git

### Tecnologia complementar futura
- SQL Server: estudos e implementação de relatórios e análises de dados.

## 4. Funcionalidades previstas

- Página inicial com apresentação dos trabalhos.
- Galeria de desenhos e ilustrações.
- Publicações com imagens, títulos e descrições.
- Perfil pessoal.
- Visualização individual dos trabalhos.
- Cadastro e gerenciamento de conteúdo.
- Armazenamento e processamento de imagens.
- Sistema de autenticação.
- Painel administrativo.

## 5. Etapas de desenvolvimento

1. Ambiente e infraestrutura.
2. Desenvolvimento do frontend.

4. Desenvolvimento do backend.
5. Integração Full Stack.
